# サブスク管理ツール (Subscription Manager)

スマートフォンから日常的に利用しているサブスクリプションサービスを簡単に登録・確認・管理できるブラウザ完結のWebツールです。

## こんなときに

- 自分がいくつのサブスクリプションに契約しているか把握したい
- 毎月・年間の固定費合計をパッと確認したい
- 無料トライアル期間の終了や次回の契約更新日を見落としたくない
- 解約したサービスも履歴として残しておきたい

## 主な機能

- **サブスクリプションの一元管理**: サービス名、料金、支払単位（月額 / 年額 / その他）、契約開始日、次回更新日、トライアル終了日、カテゴリ、メモの登録
- **支出の自動集計**: 月間および年間の支出見込みを自動計算（年額契約の月額換算に対応）
- **更新・トライアル警告**: 直近で更新日やトライアル終了日が迫っているサービスを上部にアラート表示
- **検索・絞り込み**: サービス名での検索、カテゴリ別絞り込み、ステータス（契約中 / 解約済み）切り替え
- **データ管理**: 登録データをJSON形式でエクスポート / インポート（バックアップや端末移行用）

## 使い方

### ブラウザで使う（かんたん）

1. [ツールを開く](https://zero-dev.jp/subscription-manager/) をクリックします。
2. 画面右上の「＋」ボタンを押します。
3. 「サービス名」「料金」「支払単位」「次回更新日」を入力します。
4. 必要なら、「契約開始日」「無料トライアル終了日」「カテゴリ」「支払方法」「メモ」を入力します。
5. 「登録する」を押します。
6. 一覧に登録したサービスが表示され、画面上部の合計支出が更新されます。

### データのバックアップと復元

1. 画面右上の歯車アイコン（設定）を押します。
2. 「JSONエクスポート」を押すと、登録データがファイルとして保存されます。
3. 復元する場合は、「JSONインポート」から保存したJSONファイルを選択します。

## うまくいかないとき

- 登録データが表示されないとき: ブラウザの履歴やCookie（ストレージ）を消去していないか確認してください。
- インポートに失敗するとき: 本ツールからエクスポートしたJSONファイルであることを確認してください。

## 動作環境

- モダンブラウザ（Google Chrome, Safari, Firefox, Microsoft Edge 等）
- スマートフォン（iOS, Android）および PC

## 制限・注意

- データはお使いの端末のブラウザ内（localStorage）にのみ、平文で保存されます（暗号化は行いません）。端末やブラウザにアクセスできる第三者からは閲覧可能なため、共用の端末ではご注意ください。ブラウザのプライベートモードをご利用の場合や、閲覧履歴・サイトデータを削除した場合はデータが消去されます。定期的なJSONエクスポートをおすすめします。
- 登録可能な最大件数は 500 件です。上限に達すると新規登録できません（JSONインポートも上限を超えるデータは受け付けません）。
- 保存に失敗した場合（ブラウザの空き容量不足など）は、画面に失敗の通知が表示されます。その際はJSONエクスポートでバックアップしてください。

## 外部通信

本ツールは外部サーバーへの通信を一切行いません（オフライン環境でも動作します）。入力されたサブスクリプションデータや設定情報が外部へ送信されることは一切ありません。
